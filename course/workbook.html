从打开终端开始

双击一个文件，它就打开了——但写程序不是双击。你要先学会「在终端里命令电脑做事」，这一步过了，后面才谈得上代码。
我的问题（学之前先写一句）
我学到的方法 / 结论
练习 1：按 Win 键，输入 powershell，回车。出现一个可以打字的窗口，光标在闪，就对了。
powershell
练习 2：确认电脑里有没有 Python。没有就用下面第一行装（需要联网几分钟）。
python --version
# 若提示找不到命令：
winget install -e --id Python.Python.3.12
练习 3：新建一个文件 hello.py（记事本另存为，注意后缀是 .py），写一行，然后在终端里运行它。
print("你好")

# 终端里，先 cd 到文件所在目录，再：
python hello.py
练习 4：第一个坑：不要在 PowerShell 里直接敲 Python 代码。PowerShell 自己有个 print 命令（意思是「发给打印机」），所以会报「无法初始化设备 PRN」——这不是 Python 的错，是你在错误的窗口里说话。

# PowerShell 里的结果：
# 无法初始化设备 PRN

# 正确做法一：先进入解释器
python
>>> print("你好")
>>> exit()

# 正确做法二：写进 .py 文件再运行
python hello.py
练习 5：故意写错一次，看报错长什么样——这比跑对更重要。
print(nihao)
我的结果（跑出来的数字，和预期差多少）
自测
1. 为什么不能双击 .py 文件来运行？
2. SyntaxError 和 NameError 有什么区别？

def extract(text, tries=2):
    for _ in range(tries):
        r = client.chat.completions.create(
            model="deepseek-chat",

            continue
    return None

推理为什么慢

同一个问题，有人等 0.5 秒看到第一个字，有人等 8 秒才出字。差别不在模型大小，在「两段式推理」。
我的问题（学之前先写一句）
我学到的方法 / 结论
练习 1：用流式输出，测「多久看到第一个字」和「总共多久」。
import time

t0 = time.time(); first = None; text = ""
for chunk in client.chat.completions.create(
        model="deepseek-chat",
        messages=[{"role": "user", "content": "写一段 200 字的产品介绍"}],
        stream=True):
    delta = chunk.choices[0].delta.content or ""
    if delta and first is None:
        first = time.time() - t0
    text += delta
print(f"首字 {first:.2f}s，总 {time.time()-t0:.2f}s，{len(text)} 字")
练习 2：换个长输入（比如 3000 字文档），看首字时间怎么变。
long_doc = "..." * 1000
# 只问「这段讲了什么」，输入很长、输出很短
t0 = time.time()
client.chat.completions.create(model="deepseek-chat",
    messages=[{"role": "user", "content": long_doc + "\n用一句话总结"}])
print(time.time()-t0)
练习 3：记住一个判据：首字慢 = 输入太长；出字慢 = 输出太长。
# 优化方向完全不同：
# 首字慢 → 截断/检索/缓存输入
# 出字慢 → 减少输出、换更快的模型、流式展示
我的结果（跑出来的数字，和预期差多少）
自测
1. 用户抱怨「很慢」，你该先问什么？
2. 为什么 decode 阶段 GPU 用不满？
3. KV cache 为什么能加速？代价是什么？

class Env:
    def __init__(self, rets):
        self.rets, self.i, self.pos = rets, 0, 0
    def reset(self):
        self.i, self.pos = 0, 0
        return self._obs()
    def _obs(self):
        return [self.pos, self.rets[self.i]]
    def step(self, a):          # a: -1 减仓 / 0 不动 / 1 加仓
        self.pos = max(0, min(1, self.pos + 0.5 * a))
        r = self.pos * self.rets[self.i]     # 奖励 = 仓位 × 当日收益
        self.i += 1
        done = self.i >= len(self.rets) - 1
        return self._obs(), r, done

#include <cmath>
#include <cstdio>
#include <random>

int main() {

    const int n = 10'000'000;                 // 一千万条路径

我学到的方法 / 结论
练习 1：先用 struct 把参数和公式放在一起，注意 `price()` 后面的 const——它承诺「算价格不改数据」。正态分布函数用 `std::erf` 一行写完，常数来自 C++20 的 `std::numbers`。
#include <cmath>
#include <cstdio>
#include <numbers>

struct BlackScholes {
    double S, K, r, sigma, T;

    static double cdf(double x) {
        return 0.5 * (1.0 + std::erf(x / std::numbers::sqrt2));
    }

    double price() const {
        const double sigT = sigma * std::sqrt(T);
        const double d1 = (std::log(S / K) + (r + 0.5 * sigma * sigma) * T) / sigT;
        const double d2 = d1 - sigT;
        return S * cdf(d1) - K * std::exp(-r * T) * cdf(d2);
    }
};

int main() {
    const BlackScholes bs{100.0, 100.0, 0.05, 0.2, 1.0};
    std::printf("call = %.4f\n", bs.price());
    return 0;
}
练习 2：换成 class：字段私有、构造函数校验参数。`sigma <= 0` 这种错误应该在对象出生时就炸掉，而不是算出一个负价格。注意 `price()` 和 `delta()` 都写了 const。
#include <cmath>
#include <cstdio>
#include <numbers>
#include <stdexcept>

class BlackScholes {
public:
    BlackScholes(double spot, double strike, double rate, double vol, double maturity)
        : S_(spot), K_(strike), r_(rate), sigma_(vol), T_(maturity) {
        if (S_ <= 0.0 || K_ <= 0.0) throw std::invalid_argument("spot/strike must be > 0");
        if (sigma_ <= 0.0)          throw std::invalid_argument("vol must be > 0");
        if (T_ <= 0.0)              throw std::invalid_argument("maturity must be > 0");
    }

    double price() const {
        return S_ * cdf(d1()) - K_ * std::exp(-r_ * T_) * cdf(d2());
    }

    double delta() const { return cdf(d1()); }      // call 的 delta

private:
    static double cdf(double x) { return 0.5 * (1.0 + std::erf(x / std::numbers::sqrt2)); }

    double d1() const {
        const double sigT = sigma_ * std::sqrt(T_);
        return (std::log(S_ / K_) + (r_ + 0.5 * sigma_ * sigma_) * T_) / sigT;
    }
    double d2() const { return d1() - sigma_ * std::sqrt(T_); }

    double S_, K_, r_, sigma_, T_;
};

int main() {
    const BlackScholes bs(100.0, 100.0, 0.05, 0.2, 1.0);
    std::printf("call  = %.4f\n", bs.price());
    std::printf("delta = %.4f\n", bs.delta());

    try {
        const BlackScholes bad(100.0, 100.0, 0.05, -0.2, 1.0);   // 波动率不能是负的
        std::printf("not reached: %.4f\n", bad.price());
    } catch (const std::exception& e) {
        std::printf("rejected: %s\n", e.what());
    }
    return 0;
}

#include <cmath>
#include <cstdio>
#include <numbers>
#include <stdexcept>

class BlackScholes {
public:
    BlackScholes(double spot, double strike, double rate, double vol, double maturity)
        : S_(spot), K_(strike), r_(rate), sigma_(vol), T_(maturity) {
        if (S_ <= 0.0 || K_ <= 0.0) throw std::invalid_argument("spot/strike must be > 0");
        if (sigma_ <= 0.0)          throw std::invalid_argument("vol must be > 0");
        if (T_ <= 0.0)              throw std::invalid_argument("maturity must be > 0");
    }

    double price() const { return S_ * cdf(d1()) - K_ * std::exp(-r_ * T_) * cdf(d2()); }
    double delta() const { return cdf(d1()); }
    double gamma() const { return pdf(d1()) / (S_ * sigma_ * std::sqrt(T_)); }
    double vega()  const { return S_ * std::sqrt(T_) * pdf(d1()); }

private:
    static double cdf(double x) { return 0.5 * (1.0 + std::erf(x / std::numbers::sqrt2)); }
    static double pdf(double x) { return std::exp(-0.5 * x * x) / std::sqrt(2.0 * std::numbers::pi); }

    double d1() const {
        const double sigT = sigma_ * std::sqrt(T_);
        return (std::log(S_ / K_) + (r_ + 0.5 * sigma_ * sigma_) * T_) / sigT;
    }
    double d2() const { return d1() - sigma_ * std::sqrt(T_); }

    double S_, K_, r_, sigma_, T_;
};

public:

    double strike_;

}

#include <algorithm>
#include <cstdio>
#include <functional>
#include <map>
#include <string>
#include <vector>

struct Trade  { std::string desk; double pnl; };
struct DeskPnl{ std::string desk; double pnl; };

int main() {
    const std::vector<Trade> trades = {
        {"rates",  -120.5},  {"fx",     64.0},  {"equity", -310.25},
        {"rates",    88.0},  {"credit",-12.5},  {"equity",  140.0},
    };

    std::map<std::string, double> by_desk;
    for (const auto& t : trades) by_desk[t.desk] += t.pnl;   // 一行完成分组累加

    std::vector<DeskPnl> rows;
    for (const auto& [desk, pnl] : by_desk) rows.push_back({desk, pnl});

    std::ranges::sort(rows, std::greater<>{}, &DeskPnl::pnl);   // 最后一个参数是「投影」

随机数与并发：蒙特卡洛障碍期权

你算出一个价格 8.9 元，老板只问一句「误差多少」；答不出来，这个数就不能拿出去报价。
我的问题（学之前先写一句）
我学到的方法 / 结论
练习 1：先算一条障碍期权：每天走一步 GBM，中途跌破障碍价就直接作废——break 掉，后面的步不用再抽。顺势把均值、平方和、敲出次数都记下来，误差下面要用。
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <random>

int main() {
    const int    n_paths = 1'000'000;
    const int    n_steps = 252;
    const double S0 = 100.0, K = 100.0, B = 90.0, r = 0.05, sigma = 0.2, T = 1.0;
    const double dt = T / n_steps;
    const double drift = (r - 0.5 * sigma * sigma) * dt;
    const double diff  = sigma * std::sqrt(dt);

    std::mt19937_64 rng(7);
    std::normal_distribution<double> norm(0.0, 1.0);

    double sum = 0.0, sum_sq = 0.0;
    int knocked = 0;
    for (int i = 0; i < n_paths; ++i) {
        double s = S0;
        bool out = false;
        for (int t = 0; t < n_steps; ++t) {
            s *= std::exp(drift + diff * norm(rng));
            if (s <= B) { out = true; break; }     // 敲出
        }
        const double payoff = out ? 0.0 : std::max(s - K, 0.0);
        sum    += payoff;
        sum_sq += payoff * payoff;
        if (out) ++knocked;
    }

    const double df   = std::exp(-r * T);
    const double mean = sum / n_paths;
    const double var  = sum_sq / n_paths - mean * mean;
    const double se   = df * std::sqrt(var / n_paths);

    std::printf("price = %.4f  +/-%.4f (1 se)\n", df * mean, se);
    std::printf("knock-out rate = %.1f%%\n", 100.0 * knocked / n_paths);
    return 0;
}
练习 2：把路径拆成 8 块，每块一个不同 seed，用 `std::async` 并行跑。Linux / MinGW 编译要加 `-pthread`。`f.get()` 既取回结果，也负责把异常重新抛出来。
#include <chrono>
#include <cmath>
#include <cstdio>
#include <future>
#include <random>
#include <vector>

constexpr double S0 = 100.0, K = 100.0, B = 90.0, r = 0.05, sigma = 0.2, T = 1.0;

// 只算「未折现的 payoff 之和」；seed 从外面传，保证每块独立、可复现
double mc_sum(int n_paths, int n_steps, unsigned seed) {
    const double dt    = T / n_steps;
    const double drift = (r - 0.5 * sigma * sigma) * dt;
    const double diff  = sigma * std::sqrt(dt);

    std::mt19937_64 rng(seed);
    std::normal_distribution<double> norm(0.0, 1.0);

    double sum = 0.0;
    for (int i = 0; i < n_paths; ++i) {
        double s = S0;
        bool out = false;
        for (int t = 0; t < n_steps; ++t) {
            s *= std::exp(drift + diff * norm(rng));
            if (s <= B) { out = true; break; }
        }
        if (!out && s > K) sum += s - K;
    }
    return sum;
}

int main() {
    const int n_steps   = 252;
    const int n_threads = 8;
    const int per       = 200'000;                 // 每块 20 万条
    const double df     = std::exp(-r * T);

    const auto t0 = std::chrono::steady_clock::now();
    std::vector<std::future<double>> jobs;
    for (int k = 0; k < n_threads; ++k)
        jobs.push_back(std::async(std::launch::async, mc_sum, per, n_steps, 2024u + k));

    double sum = 0.0;
    for (auto& f : jobs) sum += f.get();
    const double secs = std::chrono::duration<double>(std::chrono::steady_clock::now() - t0).count();

    const int total = per * n_threads;
    std::printf("price = %.4f\n", df * sum / total);
    std::printf("%.2f s for %d paths on %d threads (%.1f M paths/s)\n",
                secs, total, n_threads, total / secs / 1e6);
    return 0;
}

练习 1：先不装任何库：手写 2×2 矩阵乘和 Cholesky，再用 L·Lᵀ 验算回去。Cholesky 每一步只有开根号和除法，写两遍就会背了。注意验算那步第二项是 `L[j][k]`——这里写反是新手最常见的错。
#include <cmath>
#include <cstdio>

int main() {
    const double A[2][2] = {{4.0, 2.0}, {2.0, 3.0}};

    // 1. 矩阵乘 C = A * A
    double C[2][2] = {};
    for (int i = 0; i < 2; ++i)
        for (int j = 0; j < 2; ++j)
            for (int k = 0; k < 2; ++k)
                C[i][j] += A[i][k] * A[k][j];
    std::printf("A*A = [%g %g; %g %g]\n", C[0][0], C[0][1], C[1][0], C[1][1]);

    // 2. Cholesky 分解：A = L * L^T，L 是下三角
    double L[2][2] = {};
    L[0][0] = std::sqrt(A[0][0]);
    L[1][0] = A[1][0] / L[0][0];
    L[1][1] = std::sqrt(A[1][1] - L[1][0] * L[1][0]);
    std::printf("L   = [%g 0; %g %g]\n", L[0][0], L[1][0], L[1][1]);

    // 3. 验算 L * L^T 是否回到 A
    double D[2][2] = {};
    for (int i = 0; i < 2; ++i)
        for (int j = 0; j < 2; ++j)
            for (int k = 0; k < 2; ++k)
                D[i][j] += L[i][k] * L[j][k];
    std::printf("max |L*L^T - A| = %g\n",
                std::fabs(D[0][0] - A[0][0]) + std::fabs(D[1][1] - A[1][1]));
    return 0;
}

练习 3：回到业务：从收益率算协方差矩阵，再算 beta。beta 就是「与市场的协方差 ÷ 市场的方差」——一元回归不需要求逆；多因子才需要 (XᵀX)⁻¹Xᵀy，那时候直接交给 Eigen 的 `ldlt().solve()`。
#include <array>
#include <cstdio>

int main() {
    constexpr int n = 6, k = 3;      // 6 天收益率，3 个品种：0=市场 1=A 2=B
    const std::array<double, k * n> ret = {
         1.0, -2.0,  3.0,  0.0,  1.5, -0.5,   // 市场（单位 %）
         2.0, -1.0,  4.0,  1.0,  2.0,  1.0,   // A
        -1.0, -4.0,  2.0, -2.0, -1.0, -2.0,   // B
    };

    std::array<double, k> mean{};
    for (int i = 0; i < k; ++i) {
        for (int t = 0; t < n; ++t) mean[i] += ret[i * n + t];
        mean[i] /= n;
    }

    std::array<std::array<double, k>, k> cov{};
    for (int i = 0; i < k; ++i)
        for (int j = 0; j < k; ++j) {
            double s = 0.0;
            for (int t = 0; t < n; ++t)
                s += (ret[i * n + t] - mean[i]) * (ret[j * n + t] - mean[j]);
            cov[i][j] = s / (n - 1);      // 样本协方差
        }

    std::printf("cov matrix:\n");
    for (int i = 0; i < k; ++i)
        std::printf("  %7.3f %7.3f %7.3f\n", cov[i][0], cov[i][1], cov[i][2]);

    for (int i = 1; i < k; ++i)
        std::printf("beta[%d] = %.3f\n", i, cov[i][0] / cov[0][0]);
    return 0;
}

        except json.JSONDecodeError:

答案

LLM 线 · 第 1 关 · 从打开终端开始

1. 双击只是打开编辑器；要让它执行，得用解释器运行（python 文件名）。终端就是你和解释器之间的入口。

2. SyntaxError = 语法写错了（少括号、少引号），程序根本没开始跑；NameError = 语法没问题，但你用了一个没定义的名字。

3. 先看最后一行（错误类型和原因），再往上找第一个出现你自己文件名的行号。

4. 因为 PowerShell 把 print 当成了自己的别名（Out-Printer，发给打印机），代码根本没交给 Python。要么先用 python 进入解释器（>>> 提示符），要么写进 .py 文件用 python 文件名运行。

LLM 线 · 第 2 关 · 变量与运算：让电脑替你算数

1. 乘除先于加减，等价于 2 + 12 = 14。想先加就写括号。

2. 先算右边（旧 x 乘 1.05），再把结果放回 x。变量可以被覆盖，旧值就没了。

3. 前者是文字（不能做数学），后者是数字。混用会报 TypeError。

LLM 线 · 第 3 关 · 条件与重复：让电脑做判断

1. 3 次，i 分别是 0、1、2。要 1 到 3 得写 range(1, 4)。

2. `=` 是把右边装进左边；`==` 是问「两边相等吗」，返回 True/False。

3. Python 用缩进表示「哪些行属于这个 if」。不缩进就跑到 if 外面去了。

LLM 线 · 第 4 关 · Python 只学够用的

1. 前者取不到返回 None，不中断程序；后者直接抛 KeyError。解析外部返回的数据时用 get 更安全。

2. `resp[0]["content"]`——先按序号取元素，再按 key 取值。

3. 换模型、换字段名时只改一处；出错也只有一个地方要查。

LLM 线 · 第 5 关 · 调第一个 API

1. 代码会被复制、上传、截图。key 泄露后别人可以用你的额度，且很难追溯。

2. system 是给模型的长期规矩（角色、格式、语气），user 是每次的具体问题。换问题不用改 system。

3. choices 是候选列表（默认 1 个），[0] 取第一个，message 是回答对象，content 是文本。

LLM 线 · 第 6 关 · 数一数 token

1. 中文一个汉字常被切成 1–2 个 token，同样信息量下 token 数更多。

2. 输入 + 输出总共不超过 128k token；超了会被截断或直接报错。

3. 总 token 数 × 单价。先算钱，再决定要不要跑、要不要先抽样。

LLM 线 · 第 7 关 · 把文本变成可检索的向量

1. 余弦只看方向，不受文本长短影响；长文档和短句也能公平比较。

2. 同义不同词、跨语言、缩写和全称——它只认字面。

3. 切块、检索、拼提示。整篇文档太长塞不进上下文，切成小段才能只把相关的几段放进去。

LLM 线 · 第 8 关 · 让它稳定输出 JSON

1. 它保证「是合法 JSON」，不保证「字段齐全、类型对」；模型仍可能漏字段或给字符串 "null"。

2. 给 1–2 个完整示例（few-shot）、把字段类型写死、把长文本拆短、对失败样本单独改提示。

3. 没有基准就只能凭感觉说「效果不错」，出了问题也说不清是哪一类。

LLM 线 · 第 9 关 · 推理为什么慢

1. 是等第一个字慢，还是字一个一个字出得慢。前者是 prefill，后者是 decode。

2. 每一步只算一个 token，矩阵太小，算力闲着，瓶颈在显存带宽。

3. 省掉重复计算历史 token 的功夫；代价是显存，且随序列长度和并发数线性增长。

LLM 线 · 第 10 关 · 用纸笔算清显存

1. 每个参数从 2 字节压到 0.5 字节（4 位），显存降为 1/4，代价是少量精度损失。

2. KV cache 随序列长度线性增长；聊到 32k 时，光是缓存就能超过模型权重。

3. 降 KV cache：更短的上下文、更少的并发、GQA 类结构、或把一部分层放 CPU。

LLM 线 · 第 11 关 · 本地跑起来并压测

1. 8GB 显存放不下 8 份 KV cache，会退化成串行或爆显存；并发要按显存算，不是越大越好。

2. 单机试用、Windows、图省事用 Ollama；生产要吞吐、要批处理调度用 vLLM（Linux）。
