# 环境与代码：把这 8 本书跑起来

> 实测时间：2026-11-20。**Anaconda 已经装好了**，base 环境 Python 3.14 + 科学计算栈齐全，
> 真正要做的不是"装 Python"，而是**配 PATH + 为深度学习单独建一个 Python 3.12 环境**。

---

## 0. 三条结论

1. **Anaconda 可用，base 环境够跑 5 本书**（PDSH、MLCK、FTP、NLP 大部分、C++ 无关）。
   缺的是 TensorFlow（不支持 Python 3.14）、PyTorch、spaCy、xgboost。
2. **DL 两本（Hilpisch RL、Kaabar DLF）用 TF/Keras → 必须新建 Python 3.12 的 conda 环境**；
   或者用 base 里的 Python 3.14 装 PyTorch 2.15（有 3.14 轮子），把书里的 Keras 代码改写成 PyTorch。
3. **`conda` / `python` 不在 PATH 里**——所以你在普通 PowerShell 里敲 `conda` 会提示找不到。
   要么用开始菜单里的 **Anaconda Prompt**，要么 `conda init powershell` 一次，要么干脆用全路径。

## 2. 先把 PATH 配好（一次就行）

**方案 A：用 Anaconda Prompt**（最省事，不动系统）
开始菜单 → `Anaconda Prompt`，在那里敲所有命令。

**方案 B：让 PowerShell 认识 conda**（推荐，一次配置长期有效）

```powershell
& C:\Users\LENOVO\anaconda3\Scripts\conda.exe init powershell
# 关掉当前 PowerShell，重新打开
conda --version
```

**方案 C：不配，直接用全路径**（脚本/自动化场合最稳）

```powershell
$conda = 'C:\Users\LENOVO\anaconda3\Scripts\conda.exe'
$py    = 'C:\Users\LENOVO\anaconda3\python.exe'
& $py -c "import numpy; print(numpy.__version__)"
```

> 不要在 Anaconda 的 base 里直接跑书里的代码。建环境，见下一节。

## 3. 建三个环境（对应三类书）

```powershell
$conda = 'C:\Users\LENOVO\anaconda3\Scripts\conda.exe'

# ① 数据与 ML（PDSH / MLCK / FTP）——其实 base 就够，建一个是怕你把 base 搞乱
& $conda create -n quant python=3.12 -y
& $conda install -n quant -c conda-forge numpy pandas matplotlib scipy scikit-learn seaborn statsmodels jupyterlab -y

# ② 深度学习（RLF / DLF）——必须是 3.12，TF 不支持 3.14
& $conda create -n dl python=3.12 -y
& $conda activate dl
pip install tensorflow==2.19.* keras
pip install torch --index-url https://download.pytorch.org/whl/cu128
pip install jupyterlab

# ③ NLP（Blueprints）
& $conda create -n nlp python=3.12 -y
& $conda activate nlp
conda install -c conda-forge spacy gensim nltk scikit-learn pandas jupyterlab -y
pip install sentence-transformers transformers torch --index-url https://download.pytorch.org/whl/cu128
python -m spacy download en_core_web_sm
```

每个环境注册成 Jupyter 内核，切换方便：

```powershell
conda activate quant
python -m ipykernel install --user --name quant --display-name "Python (quant)"
```

## 4. 版本坑（比装包更耗时间）

你 base 里的 numpy 2.4 / pandas 3.0 / sklearn 1.9 都比书新，**书里的代码会直接报错**：

| 书里写的 | 现在 | 替代 |
|---|---|---|
| `np.float` / `np.int` / `np.bool` | numpy 2.x 已删 | `np.float64` / `int` / `bool` |
| `df.append(other)` | pandas 3.0 已删 | `pd.concat([df1, df2])` |
| `sklearn.cross_validation` | 0.20 起删 | `sklearn.model_selection.cross_val_score` |
| `plt.style.use('seaborn')` | 已改名 | `'seaborn-v0_8'` |
| `keras.optimizers.legacy.Adam`（Hilpisch RL） | Keras 3 无此模块 | 直接用 `keras.optimizers.Adam`，或固定 TF 2.13 |
| `from sklearn.preprocessing import Imputer` | 已删 | `SimpleImputer` |
| `pd.read_csv` 的 `error_bad_lines` | 已删 | `on_bad_lines='skip'` |

> 建议：跑书里的代码时**固定环境、不要随手 `conda update`**。真跑不通就查书对应版本的
> release notes，而不是硬改。

## 5. GPU：RTX 5060 Laptop 怎么用

- 这块是 **Blackwell（sm_120）**，只有 CUDA 12.8+ 的轮子认：
  ```powershell
  pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
  python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
  ```
  已确认 PyPI 上 **torch 2.15.0 有 Python 3.14 的轮子**，base 环境也能装。
- **TensorFlow**：官方不支持 Python 3.14（`pip index versions tensorflow` 直接 no matching
  distribution），所以必须用 `dl` 环境（3.12）；且 TF 的 Windows GPU 支持在 2.10 后基本停摆，
  实际多半跑 CPU——这几本书的模型都很小，CPU 够用，实在慢就上 Colab。
- 显存 8 GB：LLM 只能跑 7B 量化，书里实验按"小模型 / 小 batch"缩放。

## 8. 其他踩坑

1. **vLLM 不支持 Windows**，LLM Serving 那本要动手就装 WSL2（`wsl --install -d Ubuntu-24.04`），
   WSL 与 Windows 共用驱动，能识别 5060。
2. C++ 那本需要 MSVC 或 MSYS2：
   `winget install -e --id Microsoft.VisualStudio.2022.BuildTools`（勾"使用 C++ 的桌面开发"）+
   `winget install -e --id Kitware.CMake`。只想试语法可以上 godbolt.org。
3. PowerShell 执行策略拦住 `Activate.ps1` → `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。
4. 路径别带中文（`Downloads\新建文件夹` 会让某些老库编译失败）→ 项目放 `C:\quant\`。
5. conda 与 pip 别混着装同一个包（numpy 用 conda，就别再用 pip 覆盖它）。
