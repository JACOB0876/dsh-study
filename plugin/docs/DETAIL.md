# 8 本书学习路线

把 8 本量化 / 机器学习 / LLM 的书拆成能跟着走的课程。装上之后，在任意对话里说一句「我想学 LLM」，agent 就能带你逐关走。

## 能做什么

- 列出 4 条路线（LLM / 量化 / 文本 / C++）与每条线的关卡清单
- 取任意一关的完整内容：钩子、三个概念、动手步骤（含预期输出）、三道自测（含答案）、回书指引
- 按关键词搜索课程、概念与书的章节
- 每关末尾告诉你去书里哪一章、页码多少，以及**为什么去**（佐证 / 拓展 / 推导 / 查漏）

## 三个工具

| 工具 | 用途 |
|---|---|
| `study_catalog` | 路线概览 + 当前进度，或某条线的关卡清单（已完成打勾） |
| `study_lesson` | 某一关的完整内容，可用 `section` 只取一部分 |
| `study_search` | 搜索关卡 / 概念 / 书章 |
| `study_progress` | 查看进度、标记完成（存本机，跨会话保留） |

## 典型用法

```
你：我想学 LLM，但完全没基础
agent：（study_catalog）你有 LLM 线 11 关，前 3 关从装 Python 开始。开始第 1 关？
你：好
agent：（study_lesson start）第 1 关「从打开终端开始」……
```

## 内容范围

- 4 条路线，41 关（含 3 关零基础起步，四条线共享）
- 51 个概念卡（白话解释 + 常见误解 + 最小例子）
- 8 本书的章节索引、22 章必读清单
- 内容版本写在 `content/content.json` 的 `version` 字段，工具返回时会带上

## 兼容性

插件零依赖，不引入 `@deepseek-ai/*` 核心包，因此不会干扰 DSH 自身的加载器解析。
0.2.2 起验证过可正常激活；0.2.0 / 0.2.1 因依赖声明缺陷会导致 DSH 启动失败，请勿使用。

## 限制（请先读）

1. **不提供原书 PDF**。课程里写「《05 FTP》第 2 章 p.33–74」只是索引，书需要你自己购买或借阅。
2. **进度存在本机** `~/.dsh/study-progress.json`，不上传、不跨设备同步。删掉这个文件等于清空进度。
3. **不能替你跑代码**。动手部分的代码需要你在本机执行；插件只提供代码与预期输出。
4. **内容是我个人整理的学习路线**，不是官方教材，遇到与书冲突的地方以书为准。
